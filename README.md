
# 食事求市｜台中第二市場綜藝影展專題

## 一、專題介紹

《食事求市》是以台中第二市場為主題的綜藝短片企劃。

我們規劃由台灣與日本雙主持人進行200元美食挑戰，透過市場探索、特色小吃與攤商互動，讓更多年輕人認識傳統市場的文化與魅力。

目前影片仍在企劃階段，本網站主要展示節目構想、挑戰內容及拍攝規劃。

## 二、拍攝目的

我們希望透過輕鬆有趣的綜藝節目，吸引年輕族群認識台中第二市場。

除了介紹特色美食，也希望讓觀眾了解傳統市場的歷史、文化與人情味，增加大家實際走訪第二市場的意願。

## 三、網站內容

1. 首頁：介紹《食事求市》專題
2. 節目介紹：創作理念、拍攝目的與節目特色
3. 挑戰企劃：200元美食挑戰規則與流程
4. 分鏡腳本：預計拍攝的畫面與節目安排
5. 幕後製作：企劃發想與拍攝準備

## 四、網站設計

本網站使用 HTML5 與 CSS3 製作。

- HTML5：建立網站內容與導覽列
- CSS3：設計網站配色、字體與版面
- CSS Grid：安排主要內容與側邊欄
- RWD：讓網站適應電腦與手機螢幕
- SEO：設定網頁標題、描述與相關資訊

## 五、專案檔案

- index.html：首頁
- about.html：節目介紹
- challenge.html：挑戰企劃
- storyboard.html：分鏡腳本
- behind.html：幕後製作
- css/：網站樣式
- images/：網站圖片

## 七、Vibe Coding Prompt 紀錄

本次網站製作過程中，使用 ChatGPT 協助規劃網頁架構、撰寫 HTML 與 CSS，並依照專題需求進行修改。以下整理主要使用的 Prompt 與製作結果。

### Prompt 1：網站架構規劃

Prompt：
幫我製作一個以《食事求市》為主題的影展專題網站，需要有導覽列、側邊欄和多個分頁，並且符合老師的期末作業要求。

製作結果：
建立首頁、節目介紹、挑戰企劃、分鏡腳本及幕後製作，共五個頁面。

### Prompt 2：CSS 網頁美化

Prompt：
幫我設計適合綜藝影展主題的網頁風格，希望配色活潑一點，並且將 CSS 分成不同檔案，方便之後修改。

製作結果：
使用暖色系作為網站主要配色，並建立三個 CSS 檔案：

- style.css：網站基本樣式
- layout.css：網頁排版
- responsive.css：響應式設計

### Prompt 3：CSS Grid 排版

Prompt：
幫我使用 CSS Grid 製作網頁版面，讓主要內容顯示在左邊，節目資訊放在右邊的側邊欄。

製作結果：
使用 CSS Grid 建立雙欄式版面，讓網站內容更有條理。

### Prompt 4：RWD 響應式設計

Prompt：
幫我讓網站可以適應不同的螢幕大小，包含電腦和手機，避免文字或圖片超出畫面。

製作結果：
使用 Media Queries 調整版面，並透過 Chrome 開發者工具測試手機模式，確認網頁能正常顯示。

### Prompt 5：調整網站內容

Prompt：
我們目前只有《食事求市》的企劃書，還沒有正式拍攝影片，請幫我修改網站內容，不要寫得像影片已經完成。

製作結果：
將原本的影片欣賞改成分鏡腳本，並調整節目介紹與幕後製作的文字，讓內容符合目前的企劃進度。

### Prompt 6：新增拍攝目的

Prompt：
我想在節目介紹裡增加拍攝這支影片的目的，希望能說明為什麼選擇台中第二市場，以及想讓觀眾了解什麼。

製作結果：
新增拍攝目的，說明希望透過200元美食挑戰吸引年輕族群，介紹第二市場的美食與文化，並提高大家實際走訪市場的意願。

### Prompt 7：加入網站圖片

Prompt：
幫我在首頁加入台中第二市場的照片，並調整圖片大小，讓電腦和手機都可以正常顯示。

製作結果：
建立 images 資料夾，加入第二市場照片，並使用 CSS 設定圖片寬度與圓角效果，同時標示圖片來源及授權資訊。

## 八、製作心得

這次製作網站，讓我更熟悉 HTML 和 CSS 的使用方式，也學會如何利用 CSS Grid 和 RWD 調整網頁排版。

在製作過程中，我有依照自己的專題內容不斷修改網頁，例如調整導覽列、增加拍攝目的，以及將影片欣賞改成分鏡腳本。

透過這次作業，我也更了解如何將一份節目企劃整理成完整的多頁式網站。
